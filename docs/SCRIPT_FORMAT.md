# 대본 형식

대본은 **마크다운으로 쓰고**, `05_script_to_scenes.py` 가 공정이 읽는 JSON으로 바꿉니다.
사람은 읽고 고치기 쉬운 형식으로 쓰고, 변환은 기계가 합니다.

```bash
python3 pipeline/05_script_to_scenes.py E01_myepisode
```

## 기본 형태

```markdown
# 이 편의 제목

## s00 훅
[V] 완성본을 20초 재생. 우상단에 작은 라벨.
[N] 이건 제가 만든 5분짜리 영상입니다. 오늘은 이게 나오기까지를 보여드리겠습니다.

## s01 준비물
[V] 표. 왼쪽 항목, 오른쪽 비용.
[N] 먼저 준비물입니다. 대본은 대화형 AI, 음성은 TTS, 검사는 받아쓰기 모델입니다.
```

## 태그

| 태그 | 뜻 | 어디에 쓰이나 |
|---|---|---|
| `## s<번호> <제목>` | 씬 하나를 연다 | 번호가 씬 id (`s00`, `s01`, …), 제목은 작업용 메모 |
| `[V]` | 화면 지시 | 자기 자신에게 남기는 메모. 영상에는 안 나온다 |
| `[N]` | 내레이션 | **이 글자가 음성이 되고 자막이 된다** |
| `[S]` | 섹션 이름(선택) | 안 쓰면 자동으로 붙는다 |

- `[V]` 와 `[N]` 은 다음 줄로 이어 써도 됩니다. 빈 줄이나 다른 태그가 나오면 끊깁니다.
- `[미결]` 처럼 다른 대괄호 태그를 쓰면 그 줄부터 이어쓰기가 끝납니다. 메모로 쓰기 좋습니다.
- `##` 로 시작하지만 `s<번호>` 가 아닌 절(예: `## 미결`)은 씬으로 읽지 않습니다.

## 규칙

**씬 번호는 0부터 순서대로.** 어긋나면 스크립트가 알려줍니다.
씬을 넣거나 빼서 번호가 밀렸다면:
```bash
python3 pipeline/05_script_to_scenes.py <EP> --renumber   # 마크다운 파일까지 고쳐 준다
```

**대본을 고칠 때는 판본 번호를 올립니다.** `script_v1.md` → `script_v2.md` → …
출력은 언제나 `script/scenes_v1.json` 이라, 옛 판본을 읽으면 그 파일이 조용히 되돌아갑니다.
그래서 `--md` 를 안 주면 **가장 최신 판본**을 읽고, 옛 판본을 지목하면 종료코드 2 로 거부합니다.
그래도 옛 판본을 쓰려면 `--md script/script_v1.md --force`.
어느 판본에서 나왔는지는 출력 첫 줄과 `scenes_v1.json` 의 `source_md` 에 남습니다.

**쓰다 만 대본은 `script_v<N>.md` 로 만들지 마세요.** 인자 없는 호출은 번호가 가장 큰 파일을
고르므로, 미완성 `script_v3.md` 가 있으면 승인본을 덮습니다. 초안은 `draft.md` 처럼 **번호 없는 이름**으로
쓰다가 다 됐을 때 `script_v3.md` 로 바꾸세요. 번호가 없는 이름은 `--md script/draft.md` 로 지목하면
판본 비교 없이 그대로 읽습니다.

**`[N]` 이 없는 씬은 오류입니다.** 읽을 문장이 없으면 씬이 아닙니다.
화면만 필요한 구간은 앞뒤 씬의 길이를 늘리거나, 짧은 문장이라도 넣으세요.

**섹션은 자동으로 붙습니다.** 첫 씬 `hook`, 마지막 `outro`, 그 앞 `rule`, 나머지 `body`.
다르게 하려면 `[S] 이름` 을 씁니다. 섹션은 지금은 분류용이고 렌더에 영향을 주지 않습니다.

## 쓸 때 알아 둘 것

**한 씬 = 한 호흡 = 한 화면.** 화면이 바뀌어야 하면 씬을 나눕니다.
씬 안에서 화면을 두 번 바꾸고 싶다면 그건 두 씬입니다.

**씬 길이는 `[N]` 이 정합니다.** 화면에 맞춰 음성을 늘이지 않고, 음성을 재서 씬 길이를 만듭니다.
한국어 기준 대략 **8.5자/초**입니다. 100자면 약 12초, 170자면 약 20초입니다.
변환 스크립트가 전체 길이와 가장 긴 씬을 알려주니 참고하세요.

**20초를 넘는 씬은 나누는 게 좋습니다.** 한 화면을 20초 넘게 보면 지루하고,
자막도 길어져서 읽기 어려워집니다.

**숫자와 영문은 대본에 그대로 씁니다.** "13초", "A/B" 로 쓰세요.
음성용 한글 읽기 변환은 `10_tts_prep.py` 가 따로 만듭니다.
**자막은 대본 원문을 그대로 씁니다** — 화면에는 "13초" 로 나오고 음성만 "십삼 초" 로 읽습니다.

**`[V]` 는 나중의 나에게 주는 지시입니다.** 무엇을 띄울지만 적으면 됩니다.
실제 화면은 3단계에서 `src/<slug>/scenes.tsx` 에 컴포넌트로 붙입니다.
쓸 수 있는 카드 종류는 [remotion/README.md](../remotion/README.md) 를 보세요.

## 숫자 읽기

숫자는 `10_tts_prep.py` 가 자동으로 한글로 바꾼다. 대본에는 아라비아 숫자 그대로 쓴다.
화면 자막은 원문(`13초`)을 쓰고, 음성만 읽기(`십삼 초`)로 바뀐다.

| 대본 | 음성에 들어가는 문장 |
|---|---|
| `13초` | 십삼 초 |
| `3개` | 세 개 (고유어 셈씨는 단위로 판별) |
| `0.35초` | 영 점 삼오 초 |
| `0.08초` | 영 점 영팔 초 |
| `1.5초` | 일 점 오 초 |

소수는 점 뒤를 한 자리씩 읽는다. `0.35` 를 `영 점 삼십오` 로 읽으면 안 된다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| `[N] 이 없는 씬` 오류 | 화면만 적고 문장을 안 씀 | 문장을 넣거나 그 씬을 지운다 |
| `씬 번호가 순서대로가 아닙니다` | 중간에 씬을 넣거나 뺌 | `--renumber` |
| 내레이션에 메모가 섞임 | 이어쓰기가 안 끊김 | 메모 앞에 `[미결]` 같은 태그를 붙인다 |
| 음성이 숫자를 이상하게 읽음 | 읽기 사전에 없는 표기 | `10_tts_prep.py` 가 알려주는 토큰을 `script/tts_overrides.json` 에 추가 |
| 자막이 두 줄을 넘김 | 한 문장이 너무 김 | 문장을 나눈다(자막은 문장 단위로 잘린다) |
| 한 줄만 순식간에 지나감 | 쉼표에서 끊겨 뒷줄이 짧아짐 | 그 씬만 `50_captions_build.py <EP> --ids s14 --maxlen 46` 으로 다시 자른다 |
