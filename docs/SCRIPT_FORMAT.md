# 대본 형식

대본은 **마크다운으로 쓰고**, `05_script_to_scenes.py` 가 공정이 읽는 JSON으로 바꿉니다.
사람은 읽고 고치기 쉬운 형식으로 쓰고, 변환은 기계가 합니다.

```bash
python3 pipeline/05_script_to_scenes.py E01_myepisode
```

## 기본 형태

```markdown
# 이 편의 제목

## s00 훅
[V] 완성본을 20초 재생. 우상단에 작은 라벨.
[N] 이건 제가 만든 5분짜리 영상입니다. 오늘은 이게 나오기까지를 보여드리겠습니다.

## s01 준비물
[V] 표. 왼쪽 항목, 오른쪽 비용.
[N] 먼저 준비물입니다. 대본은 대화형 AI, 음성은 TTS, 검사는 받아쓰기 모델입니다.
```

## 태그

| 태그 | 뜻 | 어디에 쓰이나 |
|---|---|---|
| `## s<번호> <제목>` | 씬 하나를 연다 | 번호가 씬 id (`s00`, `s01`, …), 제목은 작업용 메모 |
| `[V]` | 화면 지시 | 자기 자신에게 남기는 메모. 영상에는 안 나온다 |
| `[N]` | 내레이션 | **이 글자가 음성이 되고 자막이 된다** |
| `[S]` | 섹션 이름(선택) | 안 쓰면 자동으로 붙는다 |

- `[V]` 와 `[N]` 은 다음 줄로 이어 써도 됩니다. 빈 줄이나 다른 태그가 나오면 끊깁니다.
- `[미결]` 처럼 다른 대괄호 태그를 쓰면 그 줄부터 이어쓰기가 끝납니다. 메모로 쓰기 좋습니다.
- `##` 로 시작하지만 `s<번호>` 가 아닌 절(예: `## 미결`)은 씬으로 읽지 않습니다.

## 규칙

**씬 번호는 0부터 순서대로.** 어긋나면 스크립트가 알려줍니다.
씬을 넣거나 빼서 번호가 밀렸다면:
```bash
python3 pipeline/05_script_to_scenes.py <EP> --renumber   # 마크다운 파일까지 고쳐 준다
```

**대본을 고칠 때는 판본 번호를 올립니다.** `script_v1.md` → `script_v2.md` → …
출력은 언제나 `script/scenes_v1.json` 이라, 옛 판본을 읽으면 그 파일이 조용히 되돌아갑니다.
그래서 `--md` 를 안 주면 **가장 최신 판본**을 읽고, 옛 판본을 지목하면 종료코드 2 로 거부합니다.
그래도 옛 판본을 쓰려면 `--md script/script_v1.md --force`.
어느 판본에서 나왔는지는 출력 첫 줄과 `scenes_v1.json` 의 `source_md` 에 남습니다.

**쓰다 만 대본은 `script_v<N>.md` 로 만들지 마세요.** 인자 없는 호출은 번호가 가장 큰 파일을
고르므로, 미완성 `script_v3.md` 가 있으면 승인본을 덮습니다. 초안은 `draft.md` 처럼 **번호 없는 이름**으로
쓰다가 다 됐을 때 `script_v3.md` 로 바꾸세요. 번호가 없는 이름은 `--md script/draft.md` 로 지목하면
판본 비교 없이 그대로 읽습니다.

**`[N]` 이 없는 씬은 오류입니다.** 읽을 문장이 없으면 씬이 아닙니다.
화면만 필요한 구간은 앞뒤 씬의 길이를 늘리거나, 짧은 문장이라도 넣으세요.

**섹션은 자동으로 붙습니다.** 첫 씬 `hook`, 마지막 `outro`, 그 앞 `rule`, 나머지 `body`.
다르게 하려면 `[S] 이름` 을 씁니다. 섹션은 지금은 분류용이고 렌더에 영향을 주지 않습니다.

## 쓸 때 알아 둘 것

**한 씬 = 한 호흡 = 한 화면.** 화면이 바뀌어야 하면 씬을 나눕니다.
씬 안에서 화면을 두 번 바꾸고 싶다면 그건 두 씬입니다.

**씬 길이는 `[N]` 이 정합니다.** 화면에 맞춰 음성을 늘이지 않고, 음성을 재서 씬 길이를 만듭니다.
**8.7자/초**입니다. 100자면 약 11.5초, 174자면 약 20초입니다. **가늠하는 값이지 상한이 아닙니다.**
변환 스크립트가 전체 길이와 가장 긴 씬을 알려주니 참고하세요.

- 8.7 은 `pipeline/voice.json` 의 **지금 목소리로 잰 값**입니다(E01 24씬 3,195자 / 366.1초).
  제공자·참조 음성·파라미터를 바꾸면 다시 재야 합니다. 값은 `pipeline/common.py` 의 `CHARS_PER_SEC` 한 곳에 있습니다.
- 숫자·영문이 많은 편은 이보다 느리게 읽힙니다. 편 전체로 3~4%.

**씬 길이에 상한은 없습니다.** 문제는 길이가 아니라 **긴 씬에 정지 화면 한 장만 두는 것**이라,
화면이 움직이면 길어도 견딥니다(`45_visual_plan.py` 의 점검 항목).
보여주는 것이 영상이면 그 영상이 길이를 정합니다 → `script/timing.json` 의 `min_sec`.
자막은 씬이 아니라 **문장 단위**로 잘리므로(아래 "자주 하는 실수" 표) 씬 길이와 무관합니다.

**실측이 자수 가늠보다 크게 길면 대본 문제가 아니라 음성 문제입니다.** 씬을 나눠도 안 줄어듭니다 —
E01 s07 이 145자(가늠 16.7초)에 실측 24.32초였고, 그 씬만 5.96자/초로 나머지 23씬의 7.99~9.79 밖에
있었습니다. 그럴 때는 그 씬의 음성을 다시 뽑는 것이 답입니다.

**숫자와 영문은 대본에 그대로 씁니다.** "13초", "A/B" 로 쓰세요.
음성용 한글 읽기 변환은 `10_tts_prep.py` 가 따로 만듭니다.
**자막은 대본 원문을 그대로 씁니다** — 화면에는 "13초" 로 나오고 음성만 "십삼 초" 로 읽습니다.

**`[V]` 는 나중의 나에게 주는 지시입니다.** 무엇을 띄울지만 적으면 됩니다.
실제 화면은 3단계에서 `src/<slug>/scenes.tsx` 에 컴포넌트로 붙입니다.
쓸 수 있는 카드 종류는 [remotion/README.md](../remotion/README.md) 를 보세요.

## 편 구조

무엇을 어떤 순서로 말할지는 [런북](../skills/knowhow-episode/SKILL.md) 1단계에 있습니다.
`00_new_episode.sh` 가 만드는 템플릿에 기본 구조가 들어 있습니다.

## 내레이션이 정하지 않는 길이 — `script/timing.json`

씬 길이는 원래 **내레이션으로만** 정해집니다(`LEAD + 내레이션 + GAP`). 그런데 **화면이 길이를
정해야 하는 자리**가 둘 있습니다. 둘을 이 파일 하나에 적습니다.

```json
{
  "inserts": [
    { "before": "s00", "items": [ {"sec": 9.192, "clip": "intro_orig"},
                                  {"sec": 0.4},
                                  {"sec": 9.167, "clip": "intro_clone"} ] },
    { "after":  "s18", "items": [ {"sec": 3.5, "clip": "tail_m3"} ] }
  ],
  "min_sec": { "s03": 21.4 }
}
```

### `inserts` — 내레이션이 없는 구간

훅으로 통 재생하는 클립처럼 **내레이션이 없는 구간은 씬으로 만들 수 없습니다.** `[N]` 이 없는
씬은 `05_script_to_scenes.py` 가 거부하고, 씬 슬롯에는 무음을 넣을 항이 없습니다.

- `before` / `after` 로 **어느 씬에 붙일지**만 말합니다. 앞이든 씬 사이든 같습니다.
- `clip` 이 있으면 그 클립을 **소리까지** 재생하고, 없으면 그 초만큼 화면이 빕니다(채널 바탕색).
- `clip` 이름은 `script/visual_prep.json` 의 `clips` 키입니다. 그 항목에 `"audio": true` 가
  있어야 소리가 삽니다 — `15_clip_prep.py` 는 기본이 무음입니다.
- **이 구간에는 자막이 없습니다.** 씬이 아니라서 자막이 붙을 자리가 없습니다. 원본 대사에 우리
  자막을 달아야 하면 그건 씬으로 만드는 편이 맞고, 그때는 구조가 달라집니다.

### `min_sec` — 영상이 내레이션보다 긴 씬

**보여주는 것이 영상이면 그 영상이 길이를 정합니다.** 영상이 20초인데 내레이션이 8초면 씬이
9.3초라 영상이 잘립니다. `min_sec` 은 **씬 슬롯의 하한**이고, 내레이션이 그보다 길면 내레이션이
이깁니다 — 말이 잘리는 일은 없습니다.

**씬 길이에 상한은 없습니다.** 예전에 20초 상한이 있었지만 없앴습니다 — 화면이 움직이면 길어도
견디고, 상한이 있으면 **영상을 다 보이려고 내레이션을 늘리게** 됩니다. 말이 화면을 정하는 것이
아니라 화면이 필요한 만큼 자리를 갖는 것이 맞습니다.

### 시각표가 통째로 밀립니다

`40_nar_finalize.py` 가 이 값들을 넣어 시각표를 씁니다. 그래서 자막·SRT·챕터·내레이션 트랙은
**시각표만 읽으면 되고 오프셋을 따로 더하지 않습니다.** 단계마다 더하게 하면 한 군데만
빠뜨려도 조용히 어긋납니다.

대본에는 `inserts` 구간을 **씬으로 쓰지 마세요.** 씬 번호가 밀립니다. 설명이 필요하면
`## 인트로` 같은 절로 적어 두면 되고, `05_script_to_scenes.py` 는 `[N]` 이 없는 절을
씬으로 읽지 않습니다.

## 숫자 읽기

숫자는 `10_tts_prep.py` 가 자동으로 한글로 바꾼다. 대본에는 아라비아 숫자 그대로 쓴다.
화면 자막은 원문(`13초`)을 쓰고, 음성만 읽기(`십삼 초`)로 바뀐다.

| 대본 | 음성에 들어가는 문장 |
|---|---|
| `13초` | 십삼 초 |
| `3개` | 세 개 (고유어 셈씨는 단위로 판별) |
| `0개` | 영 개 (고유어 수사에 0 이 없어 한자어로 읽는다 — **아래 규칙을 보세요**) |
| `0.35초` | 영 점 삼 오 초 |
| `0.08초` | 영 점 영 팔 초 |
| `1.5초` | 일 점 오 초 |
| `6~7세` | 육 에서 칠 세 (숫자 사이의 `~`·`-` 는 범위) |
| `−16` | 마이너스 십육 (숫자 **앞**의 빼기표는 그대로 마이너스) |

소수는 점 뒤를 **한 자리씩 띄어서** 읽는다. `0.35` 를 `영 점 삼십오` 로 읽으면 안 되고,
`영 점 삼오` 처럼 붙여도 안 된다 — 붙이면 자음동화로 자릿수가 무너진다
(`9.167` 의 `일육`[일륙]이 [이륙]으로 들려 `9.267` 이 됐다. E01 실측).
정수부는 자릿값 읽기라 띄우지 않는다 — `118` 은 `백십팔`.

**「0 + 고유어 수사」는 쓰지 않는다.** `0개`·`0컷`·`0명`·`0장`·`0번`·`0살` 은 문장으로 풀어 씁니다 —
`컷 검출 0개` 대신 `컷이 한 번도 안 끊겼습니다` 처럼. 변환기는 `영 개` 로 읽어 주지만
**한국어에서 「영 개」는 소리로 잘 안 서고**, 자막에는 `0개` 가 나가는데 소리만 외래어(`제로`)로 바꾸면
표기와 소리가 갈립니다. 그 판단은 편마다 작가가 할 몫이지 채널 사전이 일괄로 정할 것이 아닙니다.

- 이건 **사람이 지키는 규칙이고 기계가 막지 않습니다.** 변환기는 그대로 `영 개` 를 냅니다
- 검사에도 잘 안 걸립니다 — `영` 이 그 문장 다른 곳에 있으면 30단계의 숫자 대조를 통과할 수 있습니다
  (한 글자 읽기에 단위를 붙이는 규칙이 확률을 낮췄지만 0 은 아닙니다)

**소리로 못 내는 글자는 10단계가 막는다.** 한글·숫자·공백·`.` `,` `?` `!` 이 아닌 것이
전처리 뒤에도 남으면 종료코드 2 로 멈춘다. 줄표 `—` 는 쉼표로 바뀐다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| `[N] 이 없는 씬` 오류 | 화면만 적고 문장을 안 씀 | 문장을 넣거나 그 씬을 지운다 |
| `씬 번호가 순서대로가 아닙니다` | 중간에 씬을 넣거나 뺌 | `--renumber` |
| 내레이션에 메모가 섞임 | 이어쓰기가 안 끊김 | 메모 앞에 `[미결]` 같은 태그를 붙인다 |
| 음성이 숫자를 이상하게 읽음 | 읽기 사전에 없는 표기 | `10_tts_prep.py` 가 알려주는 토큰을 `script/tts_overrides.json` 에 추가 |
| 자막이 두 줄을 넘김 | 한 문장이 너무 김 | 문장을 나눈다(자막은 문장 단위로 잘린다) |
| 한 줄만 순식간에 지나감 | 쉼표에서 끊겨 뒷줄이 짧아짐 | 그 씬만 `50_captions_build.py <EP> --ids s14 --maxlen 46` 으로 다시 자른다 |
