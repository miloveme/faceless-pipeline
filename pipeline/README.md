# 공정 스크립트

모든 스크립트는 에피소드 폴더 하나를 인자로 받습니다.
**이름만 주면 됩니다** — `00_new_episode.sh` 가 만든 곳(`episodes/`, `EPISODES_DIR` 로 옮길 수 있음)에서 찾습니다.
경로로 줘도 됩니다(`episodes/E01_myepisode`, 절대경로, 현재 폴더 기준 상대경로).

```bash
python3 pipeline/40_nar_finalize.py E01_myepisode
```

번호 순서가 실행 순서입니다. 무엇을 언제 돌리는지는 `skills/knowhow-episode/SKILL.md`(런북)가 정합니다.

## 종료코드

`0` 성공 / `2` 설정·인자 오류(사람이 고쳐야 함) / `3` 검사 실패(`46_grammar_check` 등) / `1` 그 밖의 실패.

**아직 전부 맞춰지지 않았습니다.** 에피소드 폴더를 못 찾으면 규약상 2 여야 하지만 지금은 1 입니다.
`set -e` 로 도는 60·65 단계의 동작이 바뀌는 변경이라, E01 을 끝내고 `pipeline/` 전체를 한 번에 맞춥니다.

호출부는 `| tail` 로 삼키지 말고 종료코드를 확인하세요.

## 스크립트를 쓸 때 — 실제로 난 것들이 근거다

**1. 조용히 실패하지 않는다.** `50_captions_build.py --emph-only` 를 잘못된 폴더에서 돌려 세 번 연속 실패했는데 `2>&1|tail -1` 에 묻혀 못 알아챘다.
- 실패하면 **종료코드 ≠ 0**. 검사 실패 3, 설정 오류 2. 성공하면 **무엇을 몇 개 바꿨는지** 마지막 줄에 찍는다
- 호출부는 종료코드를 확인한다. `| tail` 로 삼키지 않는다. 쉘에서 `|| exit $?` 로 2 와 3 을 뭉개지 않는다

**2. 부분 적용을 세어서 보고한다.** `--ids` 로 일부만 돌리면 나머지는 옛 데이터로 남는다(E00: 5/24 를 전 씬이라 보고).
- `--ids` 를 받는 스크립트는 **처리한 씬 수 / 전체**를 찍는다(`_coverage.py`). 형식을 바꿨으면 옛 형식이 남은 곳을 세는 방법을 같이 준다

**3. 경로는 확인한 뒤 쓴다.** `48_rec_sync.py` 에서 `is_absolute()` 판정을 거꾸로 써서 항상 없는 경로를 봤다. 논리가 뒤집혀도 문법 오류가 안 난다.
- 읽기 전에 `exists()`, 없으면 **그 경로를 찍으며** 죽는다. 상대·절대 판정은 원본 문자열에 한다 — `ep / x` 는 언제나 절대경로다

**4. 저장소는 받아서 돌려 본다.** `grammar.ts` 만 넣고 그것이 부르는 `Stage.tsx` 를 빼먹어 클론하면 컴파일이 안 되는 상태로 올릴 뻔했고, `Root.tsx` 가 `.gitignore` 된 편 폴더를 import 한 채 커밋될 뻔했다. **이 기계에서는 `tsc` 가 항상 통과한다** — 폴더가 있으니까.
- `check_imports.py`(pre-commit·pre-push) 와 `check_clone_build.py`(pre-push, 새 클론에서 `tsc`) 가 막는다. 문서 치환은 결과를 **읽어 본다**

**5. 순환 참조를 만들지 않는다.** 데이터(`grammar.ts`)가 부품을 부르고 부품이 다시 데이터를 부르면 순환이 난다. **데이터는 부품을 모른다.** 잇는 일은 `captionRegistry.ts` 가 맡는다.

**6. 검사가 검사를 속이는 자리를 먼저 본다.** 스크립트를 `import` 했더니 argparse 가 돌며 산출물을 만들려 든 것(`ast` 로 읽는다), 예외를 옵션 이름만으로 뒀더니 잡으려던 바로 그 건을 통과시킨 것, 주석 속 낱말을 부품으로 센 것(주석은 걷고 센다), 상관을 안 보고 딴 칸을 잰 것(「그 칸에 그 그림이 있나」부터). **전/후는 실물로 잰다** — 옛 결함 판본이 있으면 그것으로 「전엔 통과 → 후엔 exit 3」을 보인다. 고친 것끼리 비교한 값은 재현이지 검증이 아니다.

**7. 검사 기준의 숫자는 표본을 본 뒤 긋는다.** 표본 하나(102%, 0.028)로 문턱을 정하면 추측이다. 기하로 잡히는 것(찌그러짐 2%)은 바로 긋고, 분포가 필요한 것(선명도·정지 비율)은 **찍기만** 하다가 표본이 모이면 긋는다. 어느 프레임인지 못 대는 값은 분모가 아니라 잡음이다.

**8. 같은 모양을 여러 곳이 따로 믿게 하지 않는다.** `.gitignore` 의 `e[0-9][0-9]` 와 `Root.tsx` 의 `e\d\d` 처럼 갈라지면 둘 다 에러 없이 지나간다. 정규식을 또 적는 대신 대표 경로를 `git` 에게 물어본다(`check_private.py`). 공용 읽기는 `_plan.py`·`_scene_code.py` 로 뺀다.

**새 기능을 만들면 그 기능이 조용히 틀릴 수 있는 지점을 찾아 검사를 같이 만들고, 부르는 데에 건다.** 부르는 데 없는 검사는 문서와 같다 — `check_imports.py` 는 있었는데 스테이지만 봐서 안 울렸다.

## 규약
- 상수는 `common.py` 한 곳: LEAD 0.5 / GAP 0.8 / PAD 0.35 / 내레이션 -16 / 마스터 -14 / BGM -27 LUFS.
- 서버 선택은 `hosts.py` — `hosts` 순서대로, 막히면 다음, 여럿이면 동시에.
- 목소리 설정은 `pipeline/voice.json` (`voice.example.json`을 복사해 작성). 어느 서비스로 만들지는 `provider` 가 정하고 어댑터는 `providers/` 에 있습니다 → `docs/VOICE_PROVIDERS.md`. 재시도는 시드만 바꿉니다.
- 읽기 사전 `tts_readings.json`(공통) + `<EP>/script/tts_overrides.json`(에피소드별).
- **소수는 자릿수를 띄어 읽습니다** — `9.167` → `구 점 일 육 칠`. 붙여 쓰면 자음동화로 자릿수가 무너집니다
  (`일육`[일륙] → [이륙] → `9.267`, E01 실측). 정수부는 자릿값 읽기라 안 띄웁니다.
- **10단계를 통과하는 글자는 한글·숫자·공백·`.` `,` `?` `!` 뿐입니다.** 그 밖의 것이 남으면 멈춥니다 —
  기호를 사전으로 하나씩 막으면 다음 편에서 `%`·`±`·`→`·괄호가 같은 구멍으로 지나갑니다.
  숫자 사이의 `~`·`-` 는 `에서`, 줄표 `—` 는 쉼표로 바뀝니다(숫자 **앞**의 `-` 는 그대로 마이너스).
- **소재를 바꾸면 15단계를 다시 돌립니다.** 안 돌리면 렌더에 **옛 그림이 멀쩡하게** 나옵니다 —
  화면이 안 깨지므로 사람 눈에 안 걸립니다. 55단계가 `source/` 와 `public/<slug>/` 의 시각을 대조해
  뒤처진 것이 있으면 멈춥니다(exit 3). 남이 소재를 바꿨을 때가 특히 놓치기 쉽습니다.
- **숫자는 CER 과 별개로 완전일치로 봅니다.** 118자 문장에서 한 글자는 CER 0.013 이라 문턱을 낮춰도
  못 잡고, 그만큼 조이면 정상 씬(최대 0.054 실측)이 먼저 걸립니다. 10단계가 남긴 `subs` 의 숫자 읽기가
  받아쓰기에 그대로 있는지 30단계가 대조합니다.
  - 대조하는 것은 **숫자에서 온 부분(`subs[].num`)만**입니다. 뒤에 붙은 단위·조사까지 묶으면
    `초` 가 `추` 로 들린 것 같은 뒤 글자 오독이 숫자 오독으로 잡힙니다(E01 s15). 그쪽은 CER 과 `big_diffs` 가 봅니다.
  - **대본에 나온 순서대로** 찾습니다. `영` 처럼 한 글자짜리 읽기가 앞쪽 다른 숫자(`십 점 영 사`)의
    일부에 걸려 통과하는 것을 막습니다(E01 s09).
- **`0` 은 한자어로 읽습니다** — `0개` → `영 개`. 고유어 수사에 0 이 없어 그냥 두면 숫자가 통째로
  사라집니다(`0개` → ` 개`). 1 이상은 그대로 고유어입니다(`1개` → `한 개`).
