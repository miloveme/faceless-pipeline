# 채널 공용 자산

**여러 편에서 반복해서 쓰는 것**만 여기 둡니다. 한 편에서만 쓰는 것은 그 편의 `source/` 로 갑니다.

```
assets/
  brand/      로고, 인트로·아웃트로 클립, 채널 배경, 워터마크
  refs/       생성에 반복해서 물리는 참조 — 캐릭터 시트, 스타일 기준 이미지
  music/      반복해서 쓰는 BGM
  fonts/      구글 폰트로 못 구하는 글꼴
```

## 판단 기준

| 질문 | 예 → | 아니오 → |
|---|---|---|
| 다음 편에서도 쓸 것인가 | `assets/` | `episodes/<EP>/source/` |
| 이 편의 증거인가 | `episodes/<EP>/source/` | — |

애매하면 `source/` 에 둡니다. 두 번째 편에서 또 쓰게 되면 그때 옮기세요.
미리 공용으로 만들면 안 쓰는 것이 쌓입니다.

## 주의

- 미디어 파일은 git 에 올라가지 않습니다(`.gitignore`). **이 폴더는 따로 백업하세요.**
- 여기 있는 파일을 지우거나 바꾸면 **지난 편을 다시 렌더할 때 화면이 달라집니다.**
  바꿔야 하면 이름을 새로 만들고 예전 것을 남겨 두세요 (`logo.png` → `logo_v2.png`).
- 생성에 물리는 참조(`refs/`)를 바꾸면 그 이후 편의 생김새가 바뀝니다. 목소리 참조와 같은 성격입니다.
